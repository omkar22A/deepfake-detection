# Deepfake Video Detection (CNN + LSTM)

A video deepfake classifier built with a **MobileNetV2 (CNN) feature extractor + LSTM**
temporal model, served through a **Flask** web app with a drag-and-drop UI, plus a CLI tool.

This is a portfolio / learning project. It demonstrates an end-to-end applied ML
pipeline — data preprocessing, model training with a proper train/val/test split,
evaluation, and deployment behind a web app — rather than a production-ready or
research-grade deepfake detector. See **Limitations** below for an honest breakdown.

## How it works

```
video file
    │
    ▼
[frame extraction]      15 uniformly-sampled frames
    │
    ▼
[face localization]     OpenCV Haar cascade crop (falls back to center-crop)
    │
    ▼
[CNN feature extraction]  MobileNetV2 (frozen, ImageNet weights) → 1280-d/frame
    │
    ▼
[temporal modeling]     LSTM (128 units) over the 15-frame sequence
    │
    ▼
[classification]        Dense(64, relu) → Dropout → Dense(1, sigmoid)
    │
    ▼
REAL / FAKE + confidence
```

## Project structure

```
.
├── app.py              # Flask web server
├── predict.py           # CLI: classify a single video
├── preprocess.py         # Build the training feature set from dataset/
├── train.py              # Train + evaluate the LSTM classifier
├── utils.py              # Shared frame extraction / feature extraction logic
├── requirements.txt
├── templates/index.html
├── static/{style.css, script.js}
├── dataset/{real, fake}/  # put your training videos here (not included)
├── processed_data/        # generated by preprocess.py
└── model.h5               # generated by train.py
```

## Setup

```bash
pip install -r requirements.txt
```

1. Put training videos in `dataset/real/` and `dataset/fake/` (mp4/avi/mov/mkv/webm).
   A few hundred videos, roughly balanced between classes, is a reasonable starting
   point for a demo-scale model.
2. Build features:
   ```bash
   python preprocess.py
   ```
3. Train:
   ```bash
   python train.py
   ```
   This prints a classification report and confusion matrix, and saves
   `model.h5`, `confusion_matrix.png`, and `training_curves.png`.
4. Run the web app:
   ```bash
   python app.py
   ```
   Open http://127.0.0.1:5000

Or use the CLI directly on a single video:
```bash
python predict.py path/to/video.mp4
```

## Design decisions worth calling out

- **Face cropping before feature extraction.** Deepfake artifacts are concentrated
  around the face (blending seams, eye/mouth inconsistencies), so frames are
  cropped to the detected face before being resized and fed to MobileNetV2,
  instead of passing the whole frame in.
- **Train / validation / test split (not just train/test).** Early stopping and
  checkpoint selection watch a separate validation set. The test set is only
  touched once, at the very end, to report a final, unbiased accuracy. Letting
  early stopping watch the test set directly is a common mistake that makes
  reported accuracy look better than it really is.
- **Shared `utils.py`.** Frame extraction and feature extraction logic lives in
  one place instead of being copy-pasted across `preprocess.py`, `train.py`,
  `predict.py`, and `app.py`.
- **`debug=False` in Flask.** Debug mode's interactive debugger allows arbitrary
  code execution if the app is ever reachable from outside your own machine.

## Limitations (read before treating this as more than a demo)

- **Small dataset.** Trained on a few hundred videos at most, which is small for
  a sequence model and won't capture the diversity of real-world deepfake
  generation methods.
- **No cross-dataset generalization test.** Accuracy is only reported on a
  held-out split of the *same* dataset. It's untested whether this model
  generalizes to deepfakes made with different tools than the training data.
- **Haar-cascade face detection is basic.** It's fast and dependency-free but
  less robust than modern detectors (e.g. MTCNN, RetinaFace) — it can miss
  faces at odd angles or in poor lighting.
- **Not a substitute for forensic tools.** Predictions should support human
  judgment on media authenticity, not replace it, and shouldn't be relied on
  for high-stakes decisions.

## Possible next steps

- Evaluate on a public benchmark (e.g. FaceForensics++) for a generalization check.
- Swap the Haar cascade for MTCNN/RetinaFace.
- Try a stronger backbone (EfficientNet) or a 3D-CNN baseline for comparison.
- Add k-fold cross-validation given the small dataset size.
